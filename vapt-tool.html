OWASP Top 10 (2021)

The most critical web application security risks — quick reference

📚 Reference the full OWASP Web Security Testing Guide, ASVS, and Cheat Sheet Series for detailed methodology.
A01

Broken Access Control

Users acting outside intended permissions. Includes IDOR, path traversal, privilege escalation, and CORS misconfigs.

🔧 Tools: Nuclei, ffuf, gobuster, Burp Suite, OWASP ZAP
A02

Cryptographic Failures

Sensitive data exposure due to weak/missing encryption. Includes cleartext transmission, weak hashing, hardcoded keys.

🔧 Tools: Gitleaks, TruffleHog, detect-secrets, Semgrep, Trivy
A03

Injection

SQL, NoSQL, OS command, LDAP, SSTI, XXE injection. Hostile data is sent as part of a command or query.

🔧 Tools: sqlmap, XSStrike, Nuclei, ZAP, PayloadsAllTheThings
A04

Insecure Design

Missing or ineffective control design. Includes lack of threat modeling, insecure business logic, and design flaws.

🔧 Tools: OWASP WSTG, ASVS, Manual review
A05

Security Misconfiguration

Default configs, incomplete setup, open cloud storage, verbose error messages, unnecessary features enabled.

🔧 Tools: Nikto, Nuclei, KICS, Checkov, httpx, Nmap
A06

Vulnerable and Outdated Components

Using components with known vulnerabilities. Includes outdated libraries, frameworks, and OS packages.

🔧 Tools: retire.js, Grype, Trivy, OWASP Dependency-Check, dep-scan, Syft
A07

Identification and Authentication Failures

Weak credentials, missing MFA, exposed session tokens, weak password reset, credential stuffing.

🔧 Tools: jwt_tool, Hydra, Nuclei, ZAP, Burp Suite
A08

Software and Data Integrity Failures

Code and infrastructure not protected against integrity violations. Insecure CI/CD, unsigned updates, deserialisation.

🔧 Tools: Syft, CycloneDX, Semgrep, Gitleaks, Checkov
A09

Security Logging and Monitoring Failures

Insufficient logging, missing alerting, logs not monitored. Enables attackers to persist undetected.

🔧 Tools: Falco, Manual review, OWASP WSTG (WSTG-ERRH)
A10

Server-Side Request Forgery (SSRF)

Web application fetches remote resources without validating the user-supplied URL, enabling internal access.

🔧 Tools: Interactsh, Nuclei (SSRF templates), Burp Collaborator, ffuf
